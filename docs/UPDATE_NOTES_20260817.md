# تحديث smmnine — 2026-08-17

تم تشغيل المشروع محليًا على المنفذ `3000` والتحقق من جاهزية البيئة واتصال Turso. لم تُنفّذ أثناء هذه الجولة أي عملية تسجيل دخول فعلية أو إنشاء طلب خدمة أو خصم من رصيد.

## التحسينات الجديدة

أضيفت إلى صفحة الخدمات مزامنة حية للكتالوج كل 30 ثانية، بالإضافة إلى زر تحديث يدوي، وعرض وقت آخر مزامنة، ومؤشر حالة يوضح نجاح التحديث أو فشله. عند تعذر الاتصال يظهر خطأ واضح مع زر لإعادة المحاولة بدل بقاء الصفحة في حالة تحميل غير مفهومة. كما أصبح البحث يوضح للمستخدم أنه يدعم اسم الخدمة أو رقمها.

أضيفت إلى صفحة تسجيل الدخول مراقبة صحة صامتة لمسار `/api/health` عند تحميل الصفحة، لعرض حالة المنصة: متاحة، جارٍ فحص الاتصال، أو تعذر الاتصال مؤقتًا. كما أضيفت خصائص `autocomplete` المناسبة لحقول الحساب، ووسم وصول واضح لزر إظهار وإخفاء كلمة المرور، ورسائل الخطأ المعلنة لقارئات الشاشة.

## التحقق

نجح `pnpm build`، ونجح `pnpm run healthcheck` مع استجابة HTTP 200 من `/api/health`. تم تشغيل الخادم عبر `pnpm run start:checked` على `http://localhost:3000`، ويمكن فتحه مباشرة لمراجعة التغييرات.

## تشغيل النسخة

```bash
pnpm install
pnpm run doctor
pnpm run db:init
pnpm build
pnpm run start:checked
```

يجب إنشاء ملف `.env.local` محليًا من خلال بيانات البيئة الآمنة قبل التشغيل. لم يتم تضمين `.env.local` أو مفاتيح الدفع أو ملفات كلمات المرور في نسخة ZIP غير المحمية.
