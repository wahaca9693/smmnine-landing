# إصلاح مبدّل اللغات — 2026-08-18

تم فحص صفحة الدخول بعد إعادة التصميم. البطاقة أصبحت بخلفية ذهبية داكنة غير شفافة، ولم تعد عناصر الصفحة تظهر داخلها. أظهر الاختبار أن البطاقة تُرسم تحت زر الكرة الأرضية مباشرة، ويجب إبقاء عرضها داخل حدود الشاشة الصغيرة مع الحفاظ على المحاذاة قرب الزر.

تم أيضًا تحديث قائمة اللغات داخل الحساب لإزالة طبقة التعتيم العامة واستخدام بطاقة ثابتة غير شفافة.

نتيجة البناء: `pnpm run build` نجح قبل الاختبار البصري. فحص الصحة المحلي أعاد استجابة HTTP 200.

لم تُنفّذ أي عملية تسجيل دخول أو طلب أو دفع أثناء الفحص.
