# حماية المصادقة والتسجيل

تمت إضافة حماية متعددة الطبقات إلى التسجيل وتسجيل الدخول في منصة smmnine. الحماية لا تعتمد على واجهة المتصفح وحدها، بل يُعاد التحقق من كل شيء في الخادم.

## الطبقات المفعلة

1. **Cloudflare Turnstile اختياري ومتحقق خادميًا**: الرمز يُرسل إلى Cloudflare من الخادم، ولا يُعتبر وجود عنصر الواجهة دليلًا على نجاح التحقق.
2. **Honeypot**: حقل مخفي يرفض الإرسال إذا قامت أداة آلية بملئه.
3. **حد زمني للنموذج**: تُرفض النماذج التي أُرسلت بسرعة غير منطقية أو بقيت مفتوحة فترة طويلة جدًا.
4. **محدد معدل مشترك عبر Turso**: يعتمد على عنوان IP وبصمة المتصفح واسم المستخدم/البريد، ويستمر بين عمليات النشر بدل الاعتماد على ذاكرة عملية واحدة.
5. **حماية تسجيل الدخول**: تُطبق حدود منفصلة على الدخول، مع رسالة موحدة لا تكشف وجود الحساب من عدمه.
6. **فشل مغلق**: عند تعذر مخزن الحماية يعيد الخادم 503 مؤقتًا بدل السماح بتجاوز الحماية أو إبقاء الواجهة معلقة.
7. **عدم تخزين رمز Turnstile**: الرمز يستخدم مرة واحدة أثناء الطلب ولا يحفظ في قاعدة البيانات أو الجلسة.

## متغيرات البيئة المطلوبة

في بيئة الاستضافة أضف:

```env
TURNSTILE_SITE_KEY=ضع_المفتاح_العام_هنا
TURNSTILE_SECRET_KEY=ضع_المفتاح_السري_هنا
```

يجب إنشاء مفاتيح Turnstile من لوحة Cloudflare وإضافة النطاقات الفعلية إلى إعدادات الـ widget. لا تضع `TURNSTILE_SECRET_KEY` في أي ملف يُرسل إلى المتصفح، ولا ترفع `.env.local` إلى GitHub.

عند غياب المفاتيح، تعمل حماية honeypot والتوقيت ومحددات المعدل، لكن يُنصح بتفعيل Turnstile في الإنتاج للحصول على أقوى طبقة ضد التسجيل الآلي.

## تهيئة قاعدة البيانات

يتضمن المشروع جدول `auth_attempts` ضمن تهيئة قاعدة البيانات. توجد أداة ترقية لمرة واحدة في:

```bash
node scripts/ensure-auth-table.mjs
```

شغّلها فقط مع تحميل متغيرات Turso في بيئة الإدارة، ولا تضع القيم داخل الأمر أو داخل المستودع.

## الاختبار الآمن

تم اختبار رفض طلب تسجيل مصطنع يملأ honeypot وأُعيدت استجابة HTTP 400 بسرعة دون إنشاء حساب. كما نجح بناء Next.js بعد التعديلات. لم تُنفذ أي عملية مالية أو إنشاء حساب حقيقي أثناء الاختبار.

مرجع التحقق الخادمي الرسمي: [Cloudflare Turnstile — Server-side validation](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/).
